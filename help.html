Welcome to MarkChrome

No account needed Works in your browser Saves to your computer
Getting Started

What is MarkChrome?

MarkChrome is a writing app for creating clean, well-formatted documents — things like notes, reports, README files, blog posts, or personal journals.

It uses a simple text format called Markdown. Markdown lets you add formatting (headings, bold text, lists) using plain characters like # and ** — but you never have to type them by hand if you don't want to. The toolbar buttons do it for you.

ℹ️
You don't need to know Markdown to use MarkChrome. Click any toolbar button to insert formatting automatically, or type freely in the Preview pane on the right.

The thin bar at the very bottom shows your word count, line count, and cursor position — useful when writing to a length.

Getting Started

Writing Your First Document

  • 1
    Click New in the top-right to start with a blank page. If you have unsaved changes, the app will ask before clearing.
  • 2
    Click inside the left pane and start typing your content. You'll see it appear formatted in the right pane as you type.
  • 3
    Use the toolbar buttons to add a heading, bold text, a list, or anything else. Place your cursor first, then click the button.
  • 4
    Press Ctrl + S at any time to save your file. The first time, you'll choose where to save it on your computer.
✅
A small orange dot appears next to the filename at the top whenever you have unsaved changes. It disappears as soon as you save.

Working with Tables

Tables let you present information in rows and columns — perfect for comparisons, schedules, or any structured data. MarkChrome supports creating, editing, and formatting tables in both panes.

Creating a table

  • 1
    Place your cursor where you want the table to appear — click inside either the left or right pane first.
  • 2
    Click the ⊞ Table button in the toolbar. A 3-column starter table is inserted immediately at your cursor position.
  • 3
    Click any cell in the Preview pane (right side) and type to replace the placeholder text. The Markdown source on the left updates automatically.
💡
The easiest way to edit table content is in the Preview pane — just click a cell and type, exactly like a spreadsheet.

What a table looks like

In the Markdown pane (left), a table is written using pipe characters (|) and dashes. In the Preview pane (right), it renders as a clean formatted table.

| Name    | Age | City     |
|--------|-----|----------|
| Alice  | 30  | London   |
| Bob    | 25  | New York |
← Markdown source (left pane)
Name Age City
Alice 30 London
Bob 25 New York
← Preview (right pane)

Editing cell content

You can edit a table from either pane:

Where How to edit
Preview pane (right) Click directly inside any cell and type. Changes sync to the Markdown source automatically. This is the easiest method.
Markdown pane (left) Find the row you want, locate the cell between the | pipes, and type your new value. Keep the pipes in place.

Adding more rows

In the Markdown pane, go to the last row of your table and press Enter to start a new line. Type a new row using the same pipe format:

| Carol  | 28  | Tokyo    |
A new row appears in the preview instantly.

Adding more columns

In the Markdown pane, add a new column by inserting a | New Column | into the header row, the separator row (the dashes), and every data row. Keep all rows consistent — the same number of pipes on every line.

ℹ️
The separator row (the row with dashes like |---|---|---|) tells MarkChrome that the row above it is the header. Don't delete it — the table won't render correctly without it.

Deleting a row

In the Markdown pane, select the entire line for that row (including the line break at the end) and delete it. The preview will update immediately.

Deleting the entire table

In the Markdown pane, select all the table lines — from the header row down to the last data row — and press Delete or Backspace.

⚠️
Avoid adding line breaks inside a table cell. Each row must stay on a single line in the Markdown pane or the table will break. For longer text in a cell, keep it brief or use a list outside the table instead.
Files

Open, Save & Export

Creating a new document

Click New in the toolbar. If you have unsaved work, the app will warn you first.

Opening an existing file

Click Open. A file picker will appear — choose any .md or .txt file from your computer. The file loads instantly.

Saving your work

Click Save or press Ctrl+S. The first time you save a new document, a dialog will ask where to put it. After that, saving goes straight to the same file — no dialog needed.

Saving a copy with a new name

Click Save As… to save your document to a different location or filename. Useful for creating a new version without overwriting the original.

⚠️
MarkChrome saves files directly to your computer using your browser's File System access. This works best in Google Chrome or Microsoft Edge. In other browsers, you may be prompted to download the file each time you save.

What file format does it save in?

Files are saved as plain .md (Markdown) files. These can be opened in any text editor (Notepad, VS Code, etc.) and are widely supported by publishing platforms, wikis, and note-taking apps.

Help

Common Questions

Why does the preview pane look different from the editor? ▼
The left pane shows raw Markdown text (the symbols you type), and the right pane shows how that text renders into a formatted document. They always stay in sync — any change on one side immediately appears on the other.
Can I type directly in the preview (right pane)? ▼
Yes! Click anywhere in the right pane and type or paste text. The toolbar buttons also work there. Your changes will sync back to the Markdown source on the left automatically.
I clicked H1 but the heading appeared at the bottom. What happened? ▼
This can happen in the Preview pane if you click the toolbar button before clicking inside the preview to place your cursor. Click once inside the preview pane first to position your cursor, then click the toolbar button. In the Markdown pane (left side), headings always insert at the exact cursor position.
How do I undo a change? ▼
Press Ctrl+Z (or ⌘+Z on Mac) as usual. The Markdown editor supports full undo history. In the preview pane, undo also works but may behave slightly differently depending on your browser.
Will my document be saved automatically? ▼
No — MarkChrome does not auto-save. Always press Ctrl+S regularly while working. An orange dot appears in the title bar whenever you have unsaved changes as a reminder.
Can I use MarkChrome offline? ▼
Yes. Once the HTML file is on your computer, MarkChrome works completely offline — no internet connection is needed. Just open the file in your browser.
How do I insert an image? ▼
Click the 🖼 Image button in the toolbar. A small dialog will appear asking for an image URL (a web address ending in .jpg, .png, etc.) and optional alt text. MarkChrome does not upload images from your computer — the image must be hosted online.
Can I print or export my document as a PDF? ▼
Yes. Use your browser's built-in print feature (Ctrl+P) and select "Save as PDF" as the destination. The preview pane is what will print — so what you see on the right is what you get on paper.

Tips & Tricks

Select text before clicking toolbar buttons

Highlight a word or phrase first, then click Bold or Italic — the formatting wraps your selection instead of inserting placeholder text.

Use the status bar to track your writing

The bottom bar shows a live word count. It's handy when writing to a specific length — a 500-word article, a 280-character summary, etc.

Print from the preview pane

Press Ctrl+P and your browser will print the formatted version — clean headings, tables, and all. The dark editor panel won't appear in the printout.

Convert an existing paragraph to a heading

In the Markdown pane, place your cursor on any line and click H1, H2, or H3 — the toolbar inserts the # symbol at the start of the line. You can also just type # yourself at the beginning of any line.

Tables are editable in the preview

After inserting a table with the toolbar button, click directly into any cell in the right pane and type to change the content. The Markdown source on the left updates automatically.

💡
Use Save As… to create template files. Write your standard structure once, save it, and open a copy each time you start a new document.
