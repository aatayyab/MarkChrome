    📖 MarkChrome Specification & Help Documentation

    Universal Markdown Compatibility (95%+ Coverage):

    • CommonMark & GFM: Tables, task checklists (- [x]), strikethrough (~~text~~), auto-linking.
    • YAML Front Matter: Front matter headers (--- title: ... ---) parsed and formatted for SSGs like Hugo, Jekyll, MkDocs.
    • Mermaid.js Diagrams: Render flowcharts and sequence graphs directly via ```mermaid code blocks.
    • KaTeX Math Typesetting: Inline math ($E=mc^2$) and block formulas ($$\int x dx$$).
    • Reference Links & Footnotes: Full support for footnote markers ([^1]) and reference links ([Ref][id]).
    • Diagnostic Validator: Scans for unclosed code blocks, unmatched asterisks, and broken markdown table borders.

    Keyboard Shortcuts & Productivity Triggers:
    Ctrl+S Save  |  Ctrl+F Find  |  Ctrl+B Bold  |  Ctrl+I Italic  |  Ctrl+K Link  |  Esc Zen Mode
    Shortcodes: Type //date or //table followed by Space to insert snippets.

    MarkChrome Guide & Cheat Sheet

    • # H1 / ## H2 / ### H3 — Headings
    • Bold | Italic | Strikethrough | ==Highlight==
    • [Link Text](https://...) | ![Alt](image-url)
    • - [ ] Task item | - Bullet item | 1. Numbered item
    • | Header 1 | Header 2 | — Tables
    • > Blockquote | --- Horizontal Rule
    • `code` (inline) | ```code block``` (multi-line)
