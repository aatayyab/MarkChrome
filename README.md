# MarkChrome 3.1 — Universal Markdown Workspace & Visual Editor

MarkChrome 3.1 brings robust workspace optimizations, enhanced dark-mode aesthetics, and a seamless integrated architecture built on top of our powerful Visual Editor (WYSIWYG) Mode.

### 🚀 What's New in Version 3.1
- **Integrated Workspace Architecture:** Streamlined local Markdown workflows with improved export helpers and responsive UI layout inside `app.html`.
- **Polished Dark-Mode Aesthetics:** Enhanced CSS variables and layout spacing for a cleaner, high-performance visual coding environment.

### 🚀 What's New in Version 3.0
- **Default Visual WYSIWYG Mode (Mode 2):** Click and type directly onto the rendered document surface, just like a standard word processor, with instant underlying Markdown conversion.
- **Seamless Mode Switcher:** Toggle instantly between the Visual Editor and Mode 1 (Classic Dual-Pane Markdown Workspace) via the top menu bar.
- **Advanced Document Formatting:** Full support for CommonMark & GFM tables, task checklists (`- [x]`), strikethrough, highlights, and YAML front matter parsing.
- **Rich Diagramming & Math:** Native browser rendering for Mermaid.js flowcharts/sequence diagrams and KaTeX mathematical typesetting ($E=mc^2$).
- **Enhanced File Operations & Exports:** Local file handling (`.md`, `.txt`), instant standalone HTML export, automated PDF generation via `html2pdf`, and Rich Text clipboard copying (including diagram-to-image conversion).
- **Distraction-Free Zen Mode & Outline TOC:** Quick-access collapsible table of contents sidebar and full-screen Zen writing mode (`Esc` to exit).
- **Multilingual & Multi-Theme Support:** English, Spanish, and Urdu (RTL) localization paired with Dark, Light, and High Contrast theme engines.
