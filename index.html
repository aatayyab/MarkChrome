Usage guide

Tips for using MarkChrome

Best for Markdown writing, visual drafting, and local document editing in any modern browser.

1. Protected by auto-recovery

Drafts are cached in your browser every 3 seconds. Reopen MarkChrome and your last draft is restored.

2. Save files locally

Use Ctrl+S (⌘+S on Mac) or Save regularly. Save As… makes a copy under a new name.

3. Validate before publishing

Press Validate to catch unclosed code blocks, stray asterisks and broken table rows.

4. Shortcodes

Type //date or //table then press Space to drop in a timestamp or table.

5. Paste screenshots

Copy a screenshot and paste it into the editor — it is embedded in the document automatically.

6. Keep backups

Store important Markdown files in a synced folder, external drive, or a Git repository.
