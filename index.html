Usage guide

Using MarkChrome safely

Best for Markdown writing, drafting, and local document editing in modern desktop browsers.

1. Protected by auto-recovery

Drafts are cached automatically in the background every 3 seconds to prevent data loss.

2. Save files locally

Use Ctrl+S or the Save button regularly to persist your files to disk.

3. Export options

Use the Export HTML or Export PDF buttons when sharing finished documents.

4. Keep backups

Store important Markdown files in a synced folder, external drive, or version-controlled repository.

5. Flexible themes

Toggle between light and dark preview themes to match your writing environment.

6. Clean documentation

Ideal for README files, blog drafts, technical notes, changelogs, checklists, and project plans.
