## 🎉 MarkChrome 2.0 — Universal Markdown Workspace

A major upgrade. Still free, still no account, still 100% in your browser.

### ✨ New
- 📊 Mermaid diagrams (flowcharts, sequence graphs)
- ∑ KaTeX math formulas
- 🎨 Code syntax highlighting with Copy button
- ☰ Outline sidebar (clickable table of contents)
- 🔎 Find & Replace (Ctrl+F / Ctrl+H)
- 🧘 Zen distraction-free mode
- ✅ Markdown validator
- 📋 Copy Rich Text for Word / Docs / email
- 🖼 Paste screenshots & drag-and-drop `.md` / `.txt` files
- 🌐 English, Español, اردو (RTL) interface
- 🌓 High-contrast theme
- ⚡ `//date` and `//table` shortcodes
- Refreshed website, help guide and brochure

### ⚠️ Good to know
- The preview pane is now read-only — type in the left pane.
- Needs an internet connection on open (loads diagram, math and PDF libraries).
