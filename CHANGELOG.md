# Changelog

## 2.0 — October 2026

**Major release.** MarkChrome grows from a simple editor into a full Markdown workspace.

### Added
- Mermaid diagram rendering
- KaTeX math (inline and block)
- Prism syntax highlighting + Copy button on code blocks
- Outline / table-of-contents sidebar
- Find & Replace bar (Find Next, Replace, Replace All)
- Zen (distraction-free) mode with mobile Exit button
- Markdown validator (unclosed code blocks, stray asterisks, broken table rows)
- Copy Rich Text (with diagrams converted to images for Word/Docs)
- YAML front-matter display
- Drag-and-drop file opening; paste screenshots into the document
- Interface languages: English, Español, اردو (RTL)
- High-contrast theme (third theme)
- Shortcodes `//date` and `//table`
- Ctrl+F / Ctrl+H shortcuts
- Redesigned website, help guide and brochure for 2.0

### Changed
- Preview pane is now read-only; editing happens in the Markdown source pane.
- App now loads helper libraries from CDNs (internet needed on open).

### Kept from 1.x
- Split-pane live preview, formatting toolbar, auto-recovery (every 3 s), HTML & PDF export, Save / Save As, theme toggle, cross-browser file support.

## 1.x
Initial releases: split-pane editor, toolbar, local save, auto-recovery, HTML/PDF export, theme toggle.
